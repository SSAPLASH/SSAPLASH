# 실물 드럼 그림 만들기

실물 드럼 스킨의 그림 두 벌(원근 = 큰 킷, 위에서 본 그림 = 작은 킷)을 원본 이미지에서 잘라 내는 개발용 도구다. 앱이 실행 중에 부르지 않는다. **원본 그림이 바뀌었을 때만** 한 번 돌리고, 나온 파일을 커밋한다.

## 무엇이 나오나

| 나오는 것 | 자리 | 쓰는 곳 |
| --- | --- | --- |
| 조각 이미지(WebP) 그림마다 12장 | `FE/src/components/drum/acoustic/persp/` · `top/` | 화면이 패드마다 한 장씩 불러 쓴다 |
| 패드별 자리 표 | `FE/src/domain/kit/kitArt.ts` | 헤드 중심·반지름, 링·라벨 자리, 고정 배치 자리 |
| 확인용 그림 | `FE/scripts/kit-art/out/persp-check.jpg` · `top-check.jpg` | 조각을 제자리에 다시 놓고 헤드 타원을 그린 것. 눈으로 본다 |

`kitArt.ts`는 이 도구가 쓰는 파일이다. 손으로 고치지 않는다.

## 돌리는 법

1. 원본을 `FE/scripts/kit-art/source/persp.png`(원근)와 `top.png`(위에서 본 그림)에 둔다. 용량이 커서 저장소에는 올리지 않는다(`.gitignore`).
2. `pip install pillow numpy scipy`
3. `python FE/scripts/kit-art/build.py`
4. `out/persp-check.jpg`·`out/top-check.jpg`에서 빨간 타원이 헤드에 맞고 빠진 조각이 없는지 본다.
5. `FE`에서 `npm test`를 돌린다(`src/domain/kit/kitArt.test.ts`가 구성과 자리를 검사한다).

## 원본이 지켜야 할 것

원근 그림(`persp`)은 아래를 지킨다.

- 배경은 한 가지 색이다. 도구가 가장자리 색을 배경으로 보고 뺀다.
- 드럼끼리 겹치지 않는다. 이어진 덩어리 하나를 조각 하나로 자른다.
- 심벌은 원판과 스탠드가, 하이햇은 스탠드·윗판·페달이 한 덩어리여도 된다. 크래시·라이드 원판은 금색 면으로, 하이햇 윗판과 페달은 `regions.json`에 적은 타원·다각형으로 나눈다.

위에서 본 그림(`top`)은 바닥에 무늬가 있고 심벌이 탐을 덮어도 된다(`"background": "texture"`). 도구가 밝은 곳·색이 있는 곳·아주 어두운 곳을 물체로 보고 바닥을 빼며, 심벌 원판 → 손으로 적은 사각형(킥 통·페달) → 드럼 헤드 둘레 순으로 픽셀의 주인을 정하고 남은 픽셀(스탠드 등)은 가장 가까운 조각에 준다. 이 그림의 조각은 화면에서 자리를 옮기지 않으므로, 조각을 다시 놓으면 원본과 같다.

## `regions.json`

그림 이름(`persp`·`top`)마다 아래 항목을 적는다.

| 항목 | 뜻 |
| --- | --- |
| `source` | 원본 파일 |
| `background` | `texture`면 무늬 바닥에서 물체를 남기고 영역으로 조각을 나눈다. 없으면 한 가지 색 배경을 빼고 이어진 덩어리로 나눈다 |
| `drumGrow` | 무늬 바닥 그림에서 드럼 헤드 둘레로 넓히는 폭(원본 픽셀). 테두리와 통이 이 안에 든다 |
| `scale` | 조각 이미지를 저장할 때 줄이는 배율 |
| `content` | 킷 상자로 삼을 원본 범위(왼쪽, 위, 오른쪽, 아래). 폭이 킷 단위 760이 된다 |
| `pieces[].seed` | 그 조각 위의 한 점. 이 점이 든 덩어리가 조각이 된다 |
| `pieces[].head` | 헤드 찾는 법. `gold` 심벌 원판, `white` 드럼 헤드, `hoop` 킥 앞면의 금색 테, 또는 타원 값(중심 x·y, 반지름 가로·세로) |
| `pieces[].partOf` | 다른 조각의 덩어리 안에서 `ellipse`·`rect`·`polygon`으로 떼어 내는 조각 |
| `pieces[].rects` | 무늬 바닥 그림에서 손으로 적는 사각 영역(킥 통·페달) |
| `pieces[].minus` | 떼어 낸 조각을 뺄 대상 |
| `pieces[].disc` | 그 덩어리의 금색 원판만 떼어 낸다(크래시·라이드) |
| `pieces[].top` | 받침 위에 따로 그리는 원판 조각. 타격 때 이 조각만 흔들린다 |
| `pieces[].closeDy` | 하이햇이 닫힐 때 윗판이 내려가는 거리(원본 픽셀) |

조각은 배열 순서대로 그린다(뒤 → 앞).
