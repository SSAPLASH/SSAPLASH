# 타격 이펙트 연속 그림 만들기

물·불·전기 테마가 재생하는 연속 그림(스프라이트 시트) 12장을 계산해 그리는 개발용 도구다. 앱이 실행 중에 부르지 않고 빌드도 돌리지 않는다. **모양을 바꿀 때만** 돌리고, 나온 파일을 커밋한다.

그림은 구해 온 자산이 아니라 이 스크립트가 직접 계산한 것이라 라이선스 제약이 없다.

## 무엇이 나오나

| 나오는 것 | 자리 | 쓰는 곳 |
| --- | --- | --- |
| 연속 그림(WebP) 12장: 테마 3 × 종류 4(`side-a`·`side-b`·`cymbal`·`front`) | `FE/public/fx/<id>.v1.webp` | `src/components/fx/fxSheets.ts`가 고른 테마 것만 불러온다 |

한 장은 256px 정사각 프레임 24개를 6열 4행으로 붙인 1536×1024 그림이다. 밝기를 알파로 옮긴 투명 바탕 그림이고 화면에는 더하기 합성으로 얹는다(이펙트 캔버스가 킷 위의 투명한 층이라 검은 바탕이면 킷을 가린다). 프레임 시각은 앞쪽이 촘촘하다: i번째 프레임의 시각 = 길이 × (i ÷ 23)^지수.

묶음의 길이·지수·크기(`span`)·중심(`cy`)은 `src/domain/hitFx/sheets.ts`의 표와 같아야 한다. `build.py`가 장마다 이 값을 출력하니, 설정을 바꿨으면 표도 같이 고친다.

## 돌리는 법

1. `pip install pillow numpy scipy`
2. `python FE/scripts/fx-sheets/build.py` (12장 모두, 몇 분 걸린다) 또는 `python FE/scripts/fx-sheets/build.py fire-side-a bolt-front`처럼 묶음 id를 골라서.
3. 개발 서버의 FX 랩(`/dev/fx`)에서 0.25배속으로 모양을 본다.
4. 그림을 바꿨으면 `build.py`의 `VERSION`과 `sheets.ts`의 파일 이름을 함께 올린다(브라우저 캐시를 피한다).

## 파일

| 파일 | 내용 |
| --- | --- |
| `build.py` | 묶음 id → (테마, 종류, 씨앗) 표와 저장. 384px로 그린 뒤 256px로 줄이고 검은 바탕을 투명으로 바꾼다 |
| `common.py` | 그림 크기, 잡음, 입자를 그림에 뿌리기, 프레임 시간표 |
| `water.py` | 물: 물막을 입자 약 14만 개로 두고 막 → 가닥 → 방울 순서로 찢은 뒤 밀도를 임계값으로 잘라 액체로 칠한다. 심벌은 드럼보다 덜 튄다(솟는 높이·퍼지는 거리 75%) |
| `fire.py` | 불: 불길의 겉모양에 위로 흐르는 잡음을 더해 혀 모양으로 찢고 열 색 띠에 대응시킨다. 심벌(`burst`)은 가장자리 고리가 번쩍인 뒤 불똥이 사방으로 튀어 식으며 떨어진다 |
| `bolt.py` | 전기: 가지 치는 꺾은선을 3차원으로 만들어 투영하고, 세 번의 방전이 자라고 깜빡이게 한다. 심벌은 가장자리에서 바깥으로 뻗는 방전과 튀는 불꽃을 더한다 |

종류는 보는 방향이다. `side`와 `cymbal`은 위에서 44° 각도로 내려다본 드럼과 심벌(실물 킷 큰 그림의 헤드 세로÷가로가 약 0.7이다), `front`는 정면에서 본 원판(킥, 그리고 위에서 본 킷의 모든 패드)이다. 모양은 각 파일 아래쪽의 설정 표(`DRUM`·`CYMBAL`·`KICK`/`FRONT`)와 `build.py`의 씨앗으로 정해진다. 같은 설정·씨앗이면 같은 그림이 나온다.
