# 4. 시연 시나리오

화면 이름과 버튼 이름은 `main`의 FE 기준이다. 화면 왼쪽 사이드바 메뉴는 위에서부터 **자유 연습, 리듬 게임, 악보 연습, 라이브러리, 연주 기록, 드럼 세팅**이고, 사이드바 맨 아래에 **설정**이 있다.

## 4.1 준비

| 항목 | 내용 |
| --- | --- |
| 접속 주소 | https://k15a307.p.ssafy.io |
| 브라우저 | Chrome 또는 Edge (Web Bluetooth, Web Serial 필요) |
| 기기 | 센서 스틱 2개(충전 확인), USB 동글(선택), 유선 이어폰 또는 스피커 |
| 계정 | Google 또는 SSAFY 계정으로 미리 로그인 |
| 서버 | EC2 `/health` 200, GPU 서버의 워커(`run`, `live-run`)와 Ollama 실행 확인 |
| 미리 준비할 곡 | 채보 생성에 몇 분이 걸리므로, 업로드 시연용 음원 외에 채보를 미리 만들어 둔 곡 1개 |

## 4.2 시연 순서

### ① 라이브러리: AI 채보 자동 생성

| 순서 | 화면 | 동작 (클릭 위치) | 설명할 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [라이브러리] | 오른쪽 위 [+ 올리기] 클릭 → [음원·MIDI] 탭 → 음원 파일 선택 → 업로드 | 음원만 올리면 채보가 만들어짐 |
| 2 | 라이브러리 목록 맨 위 진행 카드 | 진행 단계를 보여 준다: 접수됨 → 드럼 분리 → 채보 생성 → 완료 | 먼저 AI가 올린 파일이 **곡인지 판단**하고, 말소리·소음이면 거른다 |
| 3 | 같은 카드 | 드럼 분리 단계를 짚는다 | AI가 음원을 **드럼과 MR(반주)로 분리**한다. MR은 연주할 때 배경음으로 쓴다 |
| 4 | 같은 카드 | 채보 생성 단계를 짚는다 | **채보**란 드럼 트랙에서 언제 어떤 드럼을 치는지 뽑아 만든 연주용 악보 |
| 5 | 라이브러리 목록 | 미리 만들어 둔 곡의 [악보 연습]·[플레이] 버튼을 보여 준다 | 완료되면 바로 서비스에서 연주할 수 있다 |

### ② 드럼 세팅: 위치와 박자 맞추기

| 순서 | 화면 | 동작 (클릭 위치) | 설명할 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [드럼 세팅] | 스틱 전원을 켜고 연결 상태 타일에서 스틱 연결 확인 | 앱 설치 없이 브라우저에서 블루투스로 연결 |
| 2 | 드럼 세팅 → [시작 위치 보정] | 스틱을 정면으로 들고 잠시 멈춘다 | 시작 위치(정면)를 잡는다 |
| 3 | 드럼 세팅 → 내 드럼 → [새로 보정] | 보정 팝업에서 패드 **2개 정도만** 보정한다 | 내 자리에 맞춰 드럼 위치를 잡는다(시간 관계상 일부만) |
| 4 | 보정 팝업 | 보정한 패드를 쳐 본다. 박자가 밀리면 → 드럼 세팅의 [박자 맞추기] | **박자 보정을 직접 보여 준다.** 박에 맞춰 치면 판정 타이밍을 자동으로 맞춘다 |
| 5 | 드럼 세팅 → 판정 타이밍 · 패드 인식 범위 | 슬라이더를 짚기만 한다 | 위치와 박자는 드럼 세팅에서 세세하게 조정한다 |
| 6 | 사이드바 맨 아래 [설정] | [리듬 게임 가이드] 토글을 보여 준다 | 시스템 설정(소리, 메트로놈, 화면 표시 등)은 설정에서 바꾼다 |

### ③ 자유 연습: 타격 인식 보여 주기

| 순서 | 화면 | 동작 | 설명할 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [자유 연습] | 스네어를 둥, 둥 **작게** 친다 | |
| 2 | 자유 연습 | 스네어를 두구두구둑 **빠르게**, 더 빠르게 친다 | |
| 3 | 자유 연습 | 쿵, 쿵 **크게** 친다 | 세기와 빠른 연타도 그대로 인식한다 |
| 4 | 자유 연습 | 하이햇 → 킥 → 하이햇 → 페달 순서로 친다 | 손 패드와 발(킥·페달)을 모두 구분한다 |

### ④ 악보 연습: 학습과 AI 코칭

| 순서 | 화면 | 동작 (클릭 위치) | 설명할 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [악보 연습] | 곡 선택 화면 위의 [악보 연습 안내] 바를 보여 준다 | 세로선이 음표에 닿을 때 그 줄의 패드를 친다 |
| 2 | 같은 화면 | 학습 코스를 보여 준다 | 처음 배우는 사람을 위한 단계별 레슨 |
| 3 | 같은 화면 | 곡을 고르고 [연주 옵션]에서 **메트로놈**을 켜고 박자를 정한다 | 메트로놈 박자 설정 |
| 4 | 연주 옵션 | **연습 속도**를 [5% 느리게]·[5% 빠르게]로 조절한다 | 어려운 곡은 느리게 연습 |
| 5 | 악보 연주 화면 | 곡을 **약 30초** 연주한다 | |
| 6 | 악보 연주 화면 | 연주 중 화면에 뜨는 코칭 안내를 짚는다 | **실시간 코칭**: 늦음·놓침·손별 세기 경향을 바로 안내하고, 몇 마디마다 LLM이 짧은 안내 문구를 쓴다 |
| 7 | 결과 화면 → 리포트 | 연주가 끝나면 결과 화면으로 이동하고 리포트를 연다 | **AI 코칭 리포트**: 약점 구간, 연습 조언, LLM 총평, 맞춤 곡 추천 |

### ⑤ 리듬 게임

| 순서 | 화면 | 동작 (클릭 위치) | 설명할 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [리듬 게임] | 곡 선택 화면 위의 [리듬 게임 안내] 바를 보여 준다 | 노트가 판정선에 닿을 때 그 레인의 패드를 친다 |
| 2 | 같은 화면 | 곡을 고르고 시작해 **약 30초** 플레이한다 | PERFECT·GOOD·MISS 판정과 점수 |

### ⑥ 마무리

- 공부(악보 연습, 학습 코스, AI 코칭)와 재미(리듬 게임, 점수)를 한 서비스에서 함께 할 수 있다.
- "드럼 공부하러 오세요", "점수 내기 하자"로 마무리한다.

## 4.3 시연 중 문제가 생기면

| 증상 | 대처 |
| --- | --- |
| 스틱이 연결되지 않음 | 스틱 전원을 다시 켜고 [드럼 세팅]에서 다시 연결. 안 되면 USB 동글로 연결 |
| 판정이 한쪽으로 밀림 | [드럼 세팅] → [박자 맞추기] 또는 판정 타이밍 조정 |
| 채보 생성이 오래 걸림 | 미리 만들어 둔 곡으로 이어서 시연 |
| LLM 안내 문구가 안 나옴 | 규칙 코칭은 그대로 나온다. 시연을 계속한다 |
| 스틱 배터리 부족 | 키보드로 이어서 시연 |
