# 4. 시연 시나리오

> 초안이다. 화면 이름과 메뉴는 `main`의 FE 코드 기준이다. 실제 리허설 뒤 버튼 위치와 대사를 채운다.

## 4.1 준비

| 항목 | 내용 |
| --- | --- |
| 접속 주소 | https://k15a307.p.ssafy.io |
| 브라우저 | Chrome 또는 Edge (Web Bluetooth, Web Serial 필요) |
| 기기 | 센서 스틱 2개(충전 상태 확인), USB 동글(선택), 유선 이어폰 또는 스피커 |
| 계정 | Google 또는 SSAFY 계정 (시연용 계정 미리 로그인) |
| 서버 | EC2 `/health` 200, GPU 서버 워커 `run`·`live-run`과 Ollama 실행 확인 |
| 미리 올려 둘 곡 | 채보 생성에 몇 분이 걸리므로, 업로드 시연용 곡 외에 미리 생성해 둔 곡 1개 |

화면 왼쪽 사이드바 메뉴: 자유 연습, 리듬 게임, 악보 연습, 라이브러리, 연주 기록, 드럼 세팅

## 4.2 시연 순서

### ① 로그인

| 순서 | 화면 | 동작 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 첫 화면(랜딩) | [로그인] 클릭 → Google 또는 SSAFY 선택 | 소셜 로그인 |
| 2 | 가입 동의 (첫 로그인만) | 필수 항목 동의 후 진행 | 연주 기록 활용 동의 |

### ② 드럼 세팅

| 순서 | 화면 | 동작 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [드럼 세팅] | 스틱 전원을 켜고 연결(블루투스 직접 연결 또는 USB 동글) | 앱 설치 없이 브라우저에서 스틱 연결 |
| 2 | 드럼 세팅 → 내 드럼 | 정면을 향해 [새로 보정] 또는 [다시 보정] | 드럼 위치 보정 |
| 3 | 드럼 세팅 → 타격 확인 | 패드마다 스틱으로 쳐 본다 | 타격 시점·패드·세기 인식, 스틱 진동 |
| 4 | (선택) 박자 맞추기 | 박에 맞춰 친다 | 판정 타이밍 보정 |

### ③ 음원 업로드와 AI 채보 생성

| 순서 | 화면 | 동작 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [라이브러리] | 곡 올리기 → 음원 파일 선택 | 음원 업로드 |
| 2 | 라이브러리 | 진행 상태(대기 → 분리 → 채보 → 완료)를 보여 준다 | GPU 서버 AI가 드럼 분리·채보 생성 |
| 3 | 라이브러리 | 미리 생성해 둔 곡을 열어 난이도(쉬움·보통·어려움)를 보여 준다 | 난이도별 채보 |

### ④ 리듬 게임 연주와 실시간 코칭

| 순서 | 화면 | 동작 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [리듬 게임] | 미리 생성해 둔 곡과 난이도를 고르고 시작 | 드럼을 뺀 반주 위에서 연주 |
| 2 | 연주 화면 | 노트에 맞춰 친다 | PERFECT·GOOD·MISS 판정과 점수 |
| 3 | 연주 화면 | 일부러 늦게 치거나 한 손을 약하게 친다 | 연주 중 코칭 안내("계속 늦음", "왼손 약함" 등), 몇 마디마다 LLM 안내 문구 |

### ⑤ 결과와 AI 코칭 리포트

| 순서 | 화면 | 동작 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 결과 화면 | 연주가 끝나면 자동으로 이동 | 점수, 판정 분포, 간단 피드백 |
| 2 | 리포트 화면 | 리포트 열기 | 약점 구간, 연습 조언, LLM 총평 |
| 3 | 리포트 화면 | 구간 카드를 눌러 해당 구간을 다시 듣는다 | 약점 구간 재생 |
| 4 | 리포트 하단 | 추천 곡, 이 약점 연습하기, 비슷한 곡을 보여 준다 | 맞춤 곡 추천 |

### ⑥ 그 밖의 기능

| 순서 | 화면 | 동작 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 사이드바 [악보 연습] | 곡을 골라 연습 속도를 낮춰 연습 | 악보 연습 모드, 연습 속도 조절 |
| 2 | 사이드바 [자유 연습] | 반주를 골라 자유롭게 친다 | 자유 연습 모드 |
| 3 | 사이드바 [연주 기록] → 녹음 탭 | 녹음을 재생하고 [MIDI로 내보내기] | 연주 녹음과 MIDI 내보내기 |
| 4 | 키보드 | 스틱 없이 키보드로 친다 | 키보드 연주 |

## 4.3 시연 중 문제가 생기면

| 증상 | 대처 |
| --- | --- |
| 스틱이 연결되지 않음 | 스틱 전원을 다시 켜고 [드럼 세팅]에서 다시 연결. 안 되면 USB 동글로 연결 |
| 판정이 한쪽으로 밀림 | [드럼 세팅] → 판정 타이밍 조정 또는 박자 맞추기 |
| 채보 생성이 오래 걸림 | 미리 생성해 둔 곡으로 이어서 시연 |
| LLM 안내 문구가 안 나옴 | 규칙 코칭은 그대로 나온다. 시연을 계속한다 |
| 스틱 배터리 부족 | 키보드로 이어서 시연 |
