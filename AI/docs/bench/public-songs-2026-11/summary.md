## 정답 시각이 실제 타격보다 늦음

- 정답을 만들 때 탭 노트 위치를 분리 드럼의 librosa `onset_strength`(hop 128) 값이 가장 큰 프레임(±25ms 안)으로 옮겼다(`data/songsterr/align_song.py` 3단계)
- 같은 방식을 사람이 타격 시작을 찍은 ENST 정답 25,460개에 걸면 시각이 중앙값 13.7ms 늦어진다(사분위 9.2 ~ 19.9ms, 서비스 분리 드럼 입력). ENST 드럼 단독 입력은 14.2ms
- ENST에서 서비스 예측은 사람 정답보다 중앙값 3ms 빠르다(11/08 시간 오프셋 측정). 두 값을 더한 17ms 안팎이 공용 곡에서 나온 14.8ms와 가깝다
- 점수 영향: 예측을 10·15·20ms 늦춰도 ±50ms 8패드 F1은 0.778·0.777·0.776으로 그대로다. ±25ms에서는 0.755 → 0.770(+10ms)
- 공용 곡 채보 자체도 실제 타격보다 14ms 안팎 늦게 적혀 있다는 뜻이다. 연주 판정에 주는 영향은 측정하지 않았다

## 정답 시각 보정과 연주 판정 영향 (11/08)

- FE 기본 판정은 PERFECT ±25ms, GOOD ±60ms(`FE/src/domain/judgement.ts` DEFAULT_TIMING)
- ENST 사람 정답으로 공용 곡 방식의 정답 시각 오차를 재현하고, 사람이 실제 타격 + 박자 흔들림 N(0, σ)에 친다고 두면 PERFECT 비율이 아래처럼 바뀐다

| 흔들림 σ | 지금 채보 PERFECT / GOOD / MISS | 고친 채보 PERFECT / GOOD / MISS |
| --- | --- | --- |
| 0ms | 0.870 / 0.130 / 0.000 | 0.961 / 0.039 / 0.000 |
| 10ms | 0.789 / 0.211 / 0.000 | 0.926 / 0.074 / 0.001 |
| 15ms | 0.717 / 0.280 / 0.003 | 0.842 / 0.156 / 0.003 |
| 20ms | 0.650 / 0.332 / 0.017 | 0.742 / 0.249 / 0.009 |

- 고치는 방법 비교(ENST 사람 정답 기준): 지금 시각 − 13.7ms가 중앙값 0.0ms·|오차| 평균 7.0ms로 가장 가까웠다. 소리 세기가 오르기 시작한 곳으로 되돌리기는 −4.1ms·10.8ms, 가장 가까운 채보 예측은 −2.0ms·7.8ms
- 고친 것: `data/songsterr/fix_note_timing.py`로 31곡 `chart.json`에서 소리에 붙은 노트(곡마다 80~100%)를 13.7ms 앞당기고 offsetMs를 킥·스네어에 다시 맞춤(12~14ms 앞당겨짐). 원본은 같은 폴더 `chart_before_timefix.json`. 음원 정렬 MIDI는 바탕화면 `공용곡_MIDI_음원정렬_시각보정/`. `align_song.py`도 같은 값을 빼도록 고침
- 245 기본곡 2곡(Billie Jean·Uptown Funk, Play Drums Online 정답 기반)도 같은 방식으로 붙여 13.3·14.8ms 늦었다. 같은 방법으로 고쳐 바탕화면 `245_공용기본곡_BE전달_시각보정/`에 둠
- 고친 뒤 서비스 예측과의 시각 차이: 31곡 중앙값 −1.1ms, 245 두 곡 +0.6·−0.9ms. ±50ms 8패드 F1은 0.778 그대로, ±25ms는 0.755 → 0.768
- PDO 평가 데이터(`data/pdo_free/*/hits.tsv`)도 같은 붙이기 함수로 만들어 정답이 늦게 찍혀 있을 수 있다. 평가용이라 연주에는 영향이 없고 고치지 않았다

- 서비스 규칙의 탐 거르기(`tom_gate_ratio: 0.10`)는 탐 타격 뒤 120ms 동안 분리된 탐 트랙 에너지가 입력 드럼의 10%보다 작으면 그 탐을 버린다
- 공용 곡에서 정답 탐 자리의 ADTOF 탐 타격 1,773개 중 25%(444개)를 버렸고, 그중 Seven Nation Army 213개·Believer 120개·Congratulations 41개

### 후보와 고르기

- 후보 15개: 되살리기 켬(탐+킥 비율 0.5·0.7 × 확신 점수 0.5·0.6·0.7 × 음높이 60~130Hz 또는 제한 없음), 거르기 기준 0.05·0.03
