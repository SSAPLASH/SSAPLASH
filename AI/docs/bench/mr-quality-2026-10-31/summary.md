# 드럼리스 MR 음량·고음 손실 개선

| 항목 | 내용 |
| --- | --- |
| 작업 | S15P31A307-165 |
| 측정일 | 2026-10-30 ~ 2026-10-31 |
| 모델 | 음원 분리 모델 BS Roformer SW. 추론 모듈 -167과 같은 가중치 |
| 데이터 | ENST-Drums minus-one 64곡, MUSDB18-HQ test 50곡의 30~60초 구간, 데모 3곡 |

## 결론

- 드럼리스 MR이 작게 들리는 원인은 저장 처리였음. 크게 마스터링된 곡은 드럼을 빼면 MR 일부가 파일에 담을 수 있는 최대 크기를 넘음. develop 방식은 넘는 부분을 잘라 저장해 그 순간 소리가 찌그러졌음. 이를 막으려고 곡 전체 볼륨을 낮추면 데모 3곡 MR이 원곡보다 3.6~6.1dB 작아졌음.
- 그래서 MR 저장 처리를 리미터로 바꿨음. 최대 크기를 넘으려는 순간에만 볼륨을 낮추는 방식이라 원곡과의 음량 차이가 0.9~3.0dB로 줄고, 잘리는 샘플은 없음.
- 분리 자체 때문에 MR이 작아지지는 않음. ENST 64곡에서 지금 MR과 정답 MR의 음량 차이 중앙값이 -0.06dB임.
- MR이 원곡보다 고음이 적은 건 드럼을 빼면 원래 생기는 차이임. MUSDB 정답 MR도 원곡보다 5kHz 위가 3.7dB 작음.
- 먹먹함을 줄이려고 분리 후보 8개를 비교했지만 지금 설정보다 나은 후보는 없었음. 드럼이 칠 때 반주 일부가 드럼 쪽으로 같이 빠지는 건 지금 분리 모델의 한계로 남음.
- 드럼을 95%·90%만 빼면 fullness는 오르지만 bleedless가 ENST에서 8.2점·15.9점 떨어짐. MR에 드럼이 남아서 쓰지 않음.
- 리미터는 ENST 64곡 중 원래 피크가 -1dBFS를 넘던 24곡에서만 볼륨을 낮췄음. 중앙값으로 fullness 0.68점, bleedless 0.57점 낮아짐. 퓨전 3곡은 원래 잘릴 샘플이 0.4~0.5%로 많아 리미터가 음량을 1.2~1.4dB 낮췄고, bleedless가 13~21점 떨어졌음. 볼륨을 빠르게 낮췄다 올리는 동안 원래 거의 소리가 없던 주파수 칸에 작은 소리가 생겨서임.

## 서비스 적용

- 분리 모델과 MR 만드는 방식, 원곡 − 분리한 드럼은 그대로 둠.
- 저장 처리만 바꿈. MR은 리미터를 걸고, 드럼 트랙은 피크가 -1dBFS를 넘을 때만 파일 전체 볼륨을 같은 양만큼 낮춤. 드럼 트랙은 채보 입력이라 파형 모양을 바꾸지 않음.
- 결과 메타 `separation.json`에 `drums_gain_db`, `accompaniment_limit_db` 두 값이 추가됨.
- 리미터 때문에 드럼 트랙과 MR을 더해도 원곡과 정확히 같지 않을 수 있음. 서비스에서 두 파일을 더해 쓰는 곳은 없음.

## 채보 영향

데모 3곡의 드럼 트랙을 바꾸기 전과 후로 서비스 채보 명령에 넣어 패드별 타격 수를 셈. 바꾸기 전은 두 파일 전체 볼륨을 같은 양만큼 낮춘 드럼 트랙이고, 바꾼 뒤는 드럼 트랙 자기 피크만 보고 낮춘 것임.

| 곡 | 드럼 볼륨 변화 전 → 후 | 패드별 타격 수 차이 |
| --- | --- | --- |
| T.B.H | -4.36 → -4.33dB | 전부 같음 |
| Thunder | -3.94 → -3.55dB | 하이햇 +4, 킥 +3, 나머지 0~1 |
| 혜성 | -2.96 → -1.39dB | 크래시 67 → 80, 킥 -6, 하이햇 -5, 스네어 +5, 라이드 +4 |

- 드럼 트랙 볼륨이 1.6dB 달라진 혜성에서 크래시 수가 13개 늘었음. 채보 모델이 입력 볼륨에 따라 타격을 조금 다르게 잡음. 데모 곡은 정답 악보가 없어 어느 쪽이 맞는지는 모름.
- develop 서비스는 드럼 트랙 볼륨을 낮추지 않고 넘는 부분을 잘라 저장했음. 바꾼 뒤 드럼 트랙은 develop보다 1.4~4.3dB 작음.

## 용어

| 용어 | 뜻 |
| --- | --- |
| dBFS | 파일에 담을 수 있는 최대 크기를 0으로 둔 크기 단위. 0을 넘는 값은 16비트로 저장할 때 잘림 |
| LUFS | 사람 귀 기준 음량 단위. 방송·스트리밍 음량 표준 ITU-R BS.1770 방식. 클수록 크게 들림 |
| 리미터 | 소리가 정한 최대 크기를 넘으려는 순간에만 볼륨을 낮췄다가 되돌리는 처리. 여기서는 -1dBFS를 넘기 5ms 전부터 낮추고, 시간 상수 100ms로 천천히 되돌림. 좌우 채널을 같은 양만큼 낮춤 |
| 드럼 SDR | 분리한 드럼이 정답 드럼과 얼마나 가까운지를 dB로 잰 값. 클수록 좋음 |
| fullness | 정답 MR에 있어야 할 소리가 예측 MR에서 덜 빠졌을수록 높은 점수. 두 MR을 주파수 512칸, 약 0.02초 단위로 잘게 나눠 예측이 더 작은 칸들이 평균 몇 dB 작은지를 100 / (1 + 그 값)으로 바꿈. 분리 커뮤니티 MVSEP·MSST가 쓰는 계산 |
| bleedless | 같은 비교에서 예측이 더 큰 칸들로 계산한 점수. MR에 드럼 같은 남는 소리가 적을수록 높음 |
| 5kHz 위 fullness | fullness를 5kHz 위 칸에서만 계산한 값. 고음이 빠졌는지만 따로 봄 |
