# 음원 분리 실제 곡 품질 평가

| 항목 | 내용 |
| --- | --- |
| 작업 | S15P31A307-166 |
| 측정일 | 2026-10-29 |
| 모델 | 음원 분리 모델 BS Roformer SW. 추론 모듈 -167과 같은 가중치 |
| 비교 기준 | 분리 벤치마크 -105의 MUSDB18-HQ test 50곡 |

## 결론

- 실제 드러머 녹음에서도 분리 품질은 -105 벤치마크와 비슷한 수준임. ENST-Drums 64곡의 드럼 파일과 MR을 음량 그대로 합친 완성곡에서 드럼 SDR 중앙값이 14.78dB이고, MUSDB test는 13.40dB였음.
- 분리한 드럼에서 드럼 친 시점을 찾아 정답과 맞춰 보면, 원래 드럼 파일로 맞춰 본 것과 거의 같은 점수가 나옴. ENST 0.903 대 0.913, MDB Drums 0.946 대 0.942임. 분리하지 않은 완성곡으로 하면 0.795, 0.789로 떨어짐.
- 점수가 낮게 나온 곡은 실제 연주로 녹음한 MR 곡과 살사 곡임. 살사 세 곡은 드럼 SDR이 1.05~4.75dB이고 MR 소리가 분리된 드럼에 많이 섞임.
- MDB Drums로는 드럼 SDR을 잴 수 없음. MDB가 주는 드럼 파일이 완성곡에 들어간 드럼과 다른 소리라서임.
- 측정 중에 벤치마크 채점 결함을 찾아 고쳤음. 동시에 친 타격이 정답에 두 줄로 들어 있으면 하나가 늘 놓친 것으로 세져 타격 보존율이 낮게 나왔음.

## 서비스 적용

- 음원 분리 모델은 지금 것을 그대로 씀. 분리한 드럼으로 채보하는 지금 구조도 그대로 둠. 분리 때문에 놓치는 타격이 거의 없고, 완성곡에서 바로 찾는 것보다 낫기 때문임.
- 타악기가 많은 라틴 곡은 MR 소리가 드럼 쪽으로 섞여 들어와 채보에 없는 타격이 생길 수 있음. 이런 곡을 기본 곡으로 넣을 때는 채보 결과를 한 번 확인하는 게 좋음.

## 용어

| 용어 | 뜻 |
| --- | --- |
| dB | 두 값의 비율을 로그로 나타낸 단위. 10dB는 10배, 20dB는 100배 차이임 |
| 드럼 SDR | 정답 드럼의 에너지를 분리 결과에서 정답과 다른 부분의 에너지로 나눈 비율을 dB로 나타낸 값. 클수록 정답에 가깝고, 14.78dB면 다른 부분이 드럼의 30분의 1 정도임. 분리 논문들이 같은 방식으로 재서 결과를 바로 비교할 수 있음 |
| 드럼 SIR | 분리한 드럼에 MR 소리가 얼마나 적게 섞였는지를 dB로 잰 값. 작을수록 MR이 많이 섞인 것 |
| 타격 보존율 | 드럼 소리에서 librosa 온셋 검출로 드럼 친 시점을 찾아, 사람이 적은 정답 시점과 50ms 안에 맞는 정도를 낸 값. 분리 모델과 별개인 채점 도구이고 1이 최고임. 친 시점이 남았는지만 보고 소리가 깨끗한지는 보지 않음 |
| 반주 게인 | ENST 완성곡을 만들 때 MR 음량에 곱한 값. 1.0이면 녹음된 음량 그대로, 0.5면 절반으로 줄여 합침 |

## 데이터

| 데이터 | 곡 수 | 완성곡 | 쓰는 지표 |
| --- | --- | --- | --- |
| ENST-Drums minus-one | 64곡. 드러머 3명이 각자 자기 드럼 세트로 21·22·21곡 | 드럼 파일과 드럼리스 MR이 따로 있어 우리가 합쳐서 만듦. 정답 드럼이 완성곡 속 드럼과 정확히 같음 | 드럼 SDR, 타격 보존율 |
| MDB Drums | 23곡. 실제 밴드 녹음 | 원래 믹스된 완성곡 | 타격 보존율만 |

- ENST-Drums는 프랑스 Télécom Paris가 연구용으로 공개한 데이터임. 이용 신청서를 메일로 제출해 허가를 받은 뒤 받았음. 평가에만 쓰고 음원은 공유하지 않으며, 결과를 공개할 때는 Gillet & Richard 2006을 인용해야 함.
- ENST 완성곡은 두 가지로 만들었음. 반주 게인 1.0은 두 파일을 녹음된 음량 그대로 합친 것이고, 이때 MR이 드럼보다 중앙값으로 4.1dB 큼. MUSDB test 50곡도 반주가 드럼보다 4.3dB 커서, 실제 곡과 음량 비율이 거의 같은 조건임. 그래서 이 값을 대표로 씀.
- 반주 게인 0.5는 선행 논문들이 쓰는 1/3·2/3 비율을 MR 1/3, 드럼 2/3로 적용한 것과 같음. ENST 압축 파일에는 섞는 비율 안내가 없어서 논문 관례와 비교하려고 같이 쟀음.
- ENST 64곡 중 28곡은 MR을 실제 연주로 녹음했고, 36곡은 MIDI로 만든 MR임.
- MDB 23곡 중 12곡은 분리 모델 학습 데이터인 MUSDB18 train과 같은 녹음이라, 타격 보존율 대표값은 나머지 11곡으로 냄.

## 드럼 SDR

| 묶음 | 곡 수 | 중앙값 | 하위 25%~상위 25% |
| --- | --- | --- | --- |
| MUSDB test, -105 | 50 | 13.40 | — |
| ENST 반주 게인 1.0 | 64 | 14.78 | 11.59~17.97 |
| ENST 반주 게인 0.5 | 64 | 18.03 | 14.91~20.88 |

반주 게인 1.0에서 나눠 보면 아래와 같음.

| 나눈 기준 | 드럼 SDR 중앙값 |
| --- | --- |
| 실제 연주 MR 28곡 / MIDI MR 36곡 | 12.30 / 16.73 |
| 스틱 56곡 / 브러시 6곡 | 14.93 / 9.52 |
| 드러머 1 / 2 / 3 | 12.72 / 16.29 / 14.91 |

- 실제 곡과 가장 비슷한 조건은 반주 게인 1.0에 실제 연주 MR인 28곡이고, 12.30dB로 MUSDB test보다 1dB쯤 낮음.
- 반주 게인 0.5는 MR을 줄여서 드럼이 실제 곡보다 커진 조건이라 점수가 부풂. 곡마다 반주 게인 1.0보다 2.0~5.8dB 높았음.
- 브러시로 친 6곡은 중앙값이 스틱보다 5dB 낮음. 곡 수가 적어 참고로만 봄.

## 타격 보존율

| 묶음 | 정답 드럼 파일 | 분리하지 않은 완성곡 | 분리한 드럼 |
| --- | --- | --- | --- |
| ENST 반주 게인 1.0, 64곡 | 0.913 | 0.795 | 0.903 |
| MDB 11곡 | 0.942 | 0.789 | 0.946 |

- 세 입력에 같은 온셋 검출을 돌려 같은 정답과 맞춰 봤음. 정답 드럼 파일로 낸 값이 이 채점 도구로 나올 수 있는 기준값임.
- ENST 64곡 중 17곡은 분리한 드럼이 정답 드럼 파일보다 0.03 넘게 낮음. 가장 큰 차이는 드러머 3 살사로 0.657 대 0.900임.

## 벤치마크 채점 수정

- ENST·MDB 정답과 -105 합성곡의 MIDI 정답은 킥과 하이햇을 동시에 치면 같은 시점을 두 줄로 적음. 온셋 검출은 그 순간을 한 번만 찾음.
- 그래서 고치기 전에는 분리가 완벽해도 두 줄 중 하나가 늘 놓친 것으로 세져 재현율이 0.6대에서 막혔음. 고치기 전 값은 ENST 0.700, MDB 11곡 0.807이었음.
- 벤치마크 러너가 사람 주석이나 MIDI 정답을 채점에 넘기기 전에 30ms 안에 붙은 시점을 하나로 합치게 고쳤음. 같은 정답 시점을 쓰는 attack slope 왜곡도 같이 바로잡힘. MUSDB는 정답 시점을 드럼 스템에서 자동으로 찾아 써서 원래 겹침이 없고 값도 그대로임.
- 이 폴더의 보고서 세 개는 고친 채점으로 다시 계산한 값임. 서버에서 분리 wav를 저장하지 않은 곡은 로컬에서 같은 모델로 다시 분리해 채점했고, 서버 결과와 드럼 SDR 차이는 최대 0.02dB였음.
- -105 보고서 `docs/bench/separation-2026-10-20/`의 합성곡 값도 같은 방법으로 다시 계산했음. 7개 모델을 로컬에서 다시 분리했고 -105 결과와 드럼 SDR 차이는 0.001dB 이하였음. 드럼 SDR과 MUSDB 값은 그대로임.

| 모델 | 합성곡 타격 보존율 고치기 전 | 고친 뒤 |
| --- | --- | --- |
| bs_roformer_sw | 0.642 | 0.832 |
| bs_roformer_musdb | 0.638 | 0.829 |
| scnet_large | 0.625 | 0.814 |
| scnet_xl_ihf | 0.619 | 0.808 |
| htdemucs | 0.616 | 0.808 |
| htdemucs_ft | 0.601 | 0.790 |
| umxhq | 0.689 | 0.740 |

- 고치기 전에는 드럼 SDR이 가장 낮은 umxhq가 합성곡 타격 보존율 1위였는데, 고친 뒤에는 꼴찌가 됨. 드럼 SDR 순위와 맞게 바로잡힌 것임. -105의 모델 선정은 드럼 SDR과 MUSDB 타격 보존율로 했고 둘 다 이 결함과 상관없어서 선정 결과는 그대로임.

## 점수가 낮게 나온 곡

반주 게인 1.0에서 드럼 SDR이 낮은 다섯 곡임.

| 곡 | 드럼 SDR | 드럼 SIR |
| --- | --- | --- |
| drummer_1/107_minus-one_salsa_sticks | 1.05 | 2.03 |
| drummer_3/126_minus-one_salsa_sticks | 3.86 | 4.20 |
| drummer_1/139_MIDI-minus-one_soul-120-marvin-gaye_sticks | 4.22 | 7.15 |
| drummer_2/115_minus-one_salsa_sticks | 4.75 | 5.14 |
| drummer_3/131_minus-one_funk_sticks | 4.89 | 5.14 |

- 다섯 곡 모두 드럼 SIR이 낮음. 분리가 드럼 소리를 망가뜨린 게 아니라 MR 소리가 분리된 드럼 쪽으로 같이 빠진 것임.
- 살사는 세 드러머 모두 맨 아래에 있음. MR에 든 타악기를 모델이 드럼으로 본 것으로 추정함. 분리 결과를 들어서 확인하는 일은 남아 있음.
- MDB에서는 Shadows가 분리한 드럼 0.730으로 가장 낮지만 정답 드럼 파일도 0.696이라, 분리보다 곡 자체가 채점하기 어려운 경우임.

## MDB 드럼 SDR을 쓰지 않는 이유

- MDB를 그대로 재면 드럼 SDR 중앙값이 23곡 -1.82dB, 11곡 2.08dB로 나옴. 타격 보존율이 정답 드럼 파일 수준인 것과 맞지 않음.
- MUSDB18 train과 겹치는 12곡으로 확인했음. MUSDB는 완성곡이 스템 넷을 그대로 더한 것이라 MUSDB 드럼 스템이 완성곡 속 드럼 그 자체임.
- 두 데이터의 완성곡끼리는 5.6~77.0dB로 맞아 같은 곡임. 그런데 드럼 파일끼리는 0.0~2.6dB로 거의 맞지 않았음.
- MDB 완성곡에서 MDB 드럼 파일을 빼고 남은 소리의 5~54%가 MUSDB 드럼으로 설명됨. MDB 드럼 파일을 빼도 완성곡에 드럼이 남는다는 뜻이라, 이 파일을 정답으로 쓴 SDR은 분리 품질을 나타내지 못함. MDB가 드럼 파일을 어떻게 만들었는지는 공개 자료에서 찾지 못했음.
- MDB 데이터 쪽 문제라 분리 모델과 서비스에는 영향이 없음. 타격 보존율은 사람이 적은 정답 시점을 써서 이 문제와 상관없음.

## 한계

- ENST 완성곡은 드럼 파일과 MR을 그대로 합친 것이라, 상용 곡에 들어가는 마스터링과 압축이 없음.
- BS Roformer SW는 학습 데이터가 공개돼 있지 않아 ENST나 MDB를 학습에 썼는지 확인할 수 없음.
- 처리 시간과 메모리는 서비스 서버에서 -168이 잼. 이 측정은 서버 H200과 로컬 RTX 4070이 섞여 있어 RTF를 비교하지 않음.
- 분리 결과를 직접 들어 보는 확인은 하지 않았음. 반주 게인 1.0의 분리 wav 64곡은 로컬 `AI/data/results/sep-enst-gain1/separated/`에 있음.

## 재현

| 결과 | 만드는 법 |
