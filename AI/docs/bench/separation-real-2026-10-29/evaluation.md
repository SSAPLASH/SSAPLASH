# 음원 분리 실제 곡 품질 평가

| 항목 | 내용 |
| --- | --- |
| 작업 | S15P31A307-166 |
| 측정일 | 2026-10-29 |
| 모델 | BS Roformer SW. 서비스 추론 모듈 -167과 같은 가중치 |
| 비교 기준 | 분리 벤치마크 -105의 MUSDB18-HQ test 50곡 |

## 결론

- 실제 드러머 녹음에서도 분리 품질은 -105 벤치마크와 비슷한 수준임. 드럼과 반주를 같은 크기로 섞은 ENST-Drums 64곡에서 드럼 SDR 중앙값이 14.78dB이고, MUSDB test는 13.40dB였음.
- 분리한 드럼에서 찾은 타격은 정답 드럼에서 찾은 타격과 거의 같음. ENST에서 0.903 대 0.913, MDB Drums에서 0.946 대 0.942임. 분리 없이 원곡에서 찾으면 0.795, 0.789로 떨어짐.
- 약한 곳은 실제 연주로 녹음한 반주와 살사 곡임. 살사 세 곡은 드럼 SDR이 1.05~4.75dB로 가장 낮고, 반주 소리가 드럼 트랙에 많이 섞임.
- MDB Drums로는 드럼 SDR을 잴 수 없음. MDB의 드럼 단독 트랙이 원곡 속 드럼과 다른 신호라서임.

## 서비스 적용

- 분리 모델은 지금 것을 그대로 씀. 분리한 드럼으로 채보하는 지금 구조도 그대로 둠. 분리 때문에 놓치는 타격이 거의 없고, 원곡에서 바로 찾는 것보다 낫기 때문임.
- 타악기가 많은 라틴 곡은 반주 소리가 드럼 트랙에 섞여 들어와 채보에 없는 타격이 생길 수 있음. 이런 곡을 기본 곡으로 넣을 때는 채보 결과를 한 번 확인하는 게 좋음.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 드럼 SDR | 분리한 드럼이 정답 드럼과 얼마나 같은지를 dB로 잰 값. 클수록 좋고, 3dB 차이면 남은 오차 소리의 크기가 2배 차이임 |
| 드럼 SIR | 분리한 드럼에 반주 소리가 얼마나 적게 섞였는지를 dB로 잰 값. 작을수록 반주가 많이 섞인 것 |
| 타격 보존율 | 드럼 트랙에서 온셋 검출기로 찾은 타격 시각이 사람이 적은 정답 시각과 50ms 안에 맞는 정도를 F1로 낸 값. 1이 최고임 |
| 반주 게인 | ENST 원곡을 만들 때 반주에 곱한 값. 0.5면 드럼이 반주보다 2배 큼 |

## 데이터

| 데이터 | 곡 수 | 원곡 | 쓰는 지표 |
| --- | --- | --- | --- |
| ENST-Drums minus-one | 64곡. 드러머 3명이 각자 자기 킷으로 21·22·21곡 | 드럼 wet_mix와 반주가 따로 있어 우리가 더해서 만듦. 정답 드럼이 원곡 속 드럼과 정확히 같음 | 드럼 SDR, 타격 보존율 |
| MDB Drums | 23곡. 실제 밴드 녹음 | 원래 믹스된 원곡 | 타격 보존율만 |

- ENST 원곡은 두 가지로 만들었음. 반주 게인 0.5는 선행 논문들이 쓰는 1/3·2/3 비율을 반주 1/3, 드럼 2/3로 적용한 것과 같음. 반주 게인 1.0은 드럼과 반주를 같은 크기로 섞은 것으로, 상용 곡처럼 드럼이 두드러지지 않는 더 어려운 조건임.
- ENST 64곡 중 28곡은 반주를 실제 연주로 녹음했고, 36곡은 MIDI로 만든 반주임.
- MDB 23곡 중 12곡은 분리 모델 학습 데이터인 MUSDB18 train과 같은 녹음이라, 타격 보존율은 나머지 11곡으로 냄.
- ENST는 연구·평가 용도로만 쓸 수 있고 음원을 공유할 수 없음. 결과를 공개할 때는 Gillet & Richard 2006을 인용해야 함.

## 드럼 SDR

| 묶음 | 곡 수 | 중앙값 | 하위 25%~상위 25% |
| --- | --- | --- | --- |
| MUSDB test, -105 | 50 | 13.40 | — |
| ENST 반주 게인 0.5 | 64 | 18.03 | 14.91~20.88 |
| ENST 반주 게인 1.0 | 64 | 14.78 | 11.59~17.97 |

반주 게인 1.0에서 나눠 보면 아래와 같음.

| 나눈 기준 | 드럼 SDR 중앙값 |
| --- | --- |
| 실제 연주 반주 28곡 / MIDI 반주 36곡 | 12.30 / 16.73 |
| 스틱 56곡 / 브러시 6곡 | 14.93 / 9.52 |
| 드러머 1 / 2 / 3 | 12.72 / 16.29 / 14.91 |

- 실제 곡과 가장 비슷한 조건은 반주 게인 1.0에 실제 연주 반주인 28곡이고, 12.30dB로 MUSDB test보다 1dB쯤 낮음.
- 반주 게인 0.5 결과는 드럼이 커서 쉬운 조건이라 대표값으로 쓰지 않음. 곡마다 반주 게인 1.0보다 2.0~5.8dB 높았음.
- 브러시로 친 6곡은 중앙값이 스틱보다 5dB 낮음. 곡 수가 적어 참고로만 봄.

## 타격 보존율

| 묶음 | 정답 드럼 | 원곡 그대로 | 분리 드럼 |
| --- | --- | --- | --- |
| ENST 반주 게인 1.0, 64곡 | 0.913 | 0.795 | 0.903 |
| MDB 11곡 | 0.942 | 0.789 | 0.946 |

- 세 입력에 같은 온셋 검출기를 돌려 같은 정답과 비교했음. 정답 드럼에서 낸 값을 이 검출기의 기준값으로 봄.
- 정답 시각은 30ms 안에 붙은 시각을 하나로 합친 뒤 채점했음. ENST와 MDB 주석은 킥과 하이햇을 같이 치면 같은 시각을 두 줄로 적는데, 검출기는 한 번만 잡아서 그대로 채점하면 재현율이 막힘. 합치지 않은 값은 벤치마크 보고서 summary.md에 있고 ENST 0.700, MDB 0.807임.
- ENST 64곡 중 17곡은 분리 드럼이 정답 드럼보다 0.03 넘게 낮음. 가장 큰 차이는 드러머 3 살사로 0.657 대 0.900임.

## 분리가 약한 곡

반주 게인 1.0에서 드럼 SDR이 낮은 다섯 곡임.

| 곡 | 드럼 SDR | 드럼 SIR |
| --- | --- | --- |
| drummer_1/107_minus-one_salsa_sticks | 1.05 | 2.03 |
| drummer_3/126_minus-one_salsa_sticks | 3.86 | 4.20 |
| drummer_1/139_MIDI-minus-one_soul-120-marvin-gaye_sticks | 4.22 | 7.15 |
| drummer_2/115_minus-one_salsa_sticks | 4.75 | 5.14 |
| drummer_3/131_minus-one_funk_sticks | 4.89 | 5.14 |

- 다섯 곡 모두 드럼 SIR이 낮음. 분리가 드럼 소리를 망가뜨린 게 아니라 반주 소리가 드럼 트랙으로 같이 빠진 것임.
- 살사는 세 드러머 모두 맨 아래에 있음. 반주에 든 타악기를 모델이 드럼으로 본 것으로 추정함. 분리 결과를 들어서 확인하는 일은 남아 있음.
- MDB에서는 Shadows가 분리 드럼 0.730으로 가장 낮지만 정답 드럼도 0.696이라, 분리보다 곡 자체가 검출하기 어려운 경우임.

## MDB 드럼 SDR을 쓰지 않는 이유

- MDB를 그대로 재면 드럼 SDR 중앙값이 23곡 -1.82dB, 11곡 2.08dB로 나옴. 타격 보존율이 정답 드럼 수준인 것과 맞지 않음.
- MUSDB18 train과 겹치는 12곡으로 확인했음. MUSDB는 원곡이 스템 넷을 그대로 더한 것이라 MUSDB 드럼 스템이 원곡 속 드럼 그 자체임.
- 두 데이터의 원곡끼리는 5.6~77.0dB로 맞아 같은 곡임. 그런데 드럼 트랙끼리는 0.0~2.6dB로 서로 다른 신호였음.
- MDB 원곡에서 MDB 드럼 트랙을 빼고 남은 소리의 5~54%가 MUSDB 드럼으로 설명됨. MDB 드럼 트랙을 정답으로 빼도 원곡에 드럼이 남는다는 뜻이라, 이 트랙을 정답으로 쓴 SDR은 분리 품질을 나타내지 못함.

## 한계

- ENST 원곡은 드럼과 반주를 그대로 더한 것이라, 상용 곡에 들어가는 마스터링과 압축이 없음.
- BS Roformer SW는 학습 데이터가 공개돼 있지 않아 ENST나 MDB를 학습에 썼는지 확인할 수 없음.
- 처리 시간과 메모리는 서비스 서버에서 -168이 잼. 이 측정은 서버 H200과 로컬 RTX 4070이 섞여 있어 RTF를 비교하지 않음.
- 분리 결과를 직접 들어 보는 확인은 하지 않았음. 반주 게인 1.0의 분리 wav 64곡은 로컬 `AI/data/results/sep-enst-gain1/separated/`에 있음.
