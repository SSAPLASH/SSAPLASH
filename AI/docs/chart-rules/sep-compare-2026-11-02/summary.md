# 서비스 채보 모델 교체: 드럼 분리 입력 비교 결과 (S15P31A307-241, S15P31A307-243)

측정일 2026-11-02 · 입력 BS-Roformer SW로 노래에서 뽑은 드럼(서비스와 같음) · F1 ±50ms · 규칙 pk_gap30 + 크래시 가중치 0.7 · MDB 23곡, ENST 반주 곡 64곡

## 결론

- 서비스 채보 모델을 패드마다 다른 ADTOF 가중치를 쓰는 조합으로 바꿈(`configs/bench/transcribers/adtof_drumsep/adtof_drumsep_realrec.yaml`). 서비스 기준 8패드 F1이 MDB 0.844 → 0.886, ENST 0.790 → 0.830
- 패드별 가중치
  - 킥·스네어·하이햇·하이햇 페달: 실제 녹음 학습 모델 `tom_6cls_real_full`(E-GMD·STAR에 ENST·MDB 실제 녹음을 더해 학습)
  - 탐 3종: 원래 ADTOF 가중치. 실제 녹음 학습 모델은 처음 보는 드럼 세트의 킥을 탐으로 적어 ENST 탐 3종 F1이 0.261 → 0.129로 떨어짐
  - 크래시·라이드: 7클래스 실제 녹음 학습 모델 `tom_7cls_real_full`(크래시·라이드를 모델이 직접 나눠 냄)
- 하이햇 페달은 하이햇으로 합쳐 채보 JSON 8패드를 유지함. BE 결과 검증이 8패드만 받음
- 탐은 탐을 친 위치를 찾는 것부터 약함. 탐 종류를 무시해도 탐 F1이 MDB 0.68, ENST 0.42라 패드 판정 완화(FE)와 편집 기능으로 보완할 몫으로 남김

## 3. 채점 방법

- 실제 녹음 학습 모델은 ENST·MDB로 학습해서 같은 곡으로 채점하면 점수가 부풂. 그래서 ENST 드러머 하나와 MDB 곡 묶음 하나를 빼고 학습한 버전 3개(`*_real_no_d1~3`)로 각자 안 본 곡만 채점해 합침. 묶음 표 `configs/train/real_check/folds.yaml`
- 서비스용 가중치는 뺀 곡 없이 전체로 학습한 `*_real_full`. 합성 데이터 점수가 채점용 버전과 같은 수준인 것을 확인함(GMD 9가지 F1 0.906, 채점용 0.906~0.910)
- 서버 예측 `notebooks/cym7_real_server.ipynb` · 채점 `scripts/score_sep_compare.py`

## 4. 서비스 반영 시 필요한 것

- 워커 가중치 폴더(`SSAPLASH_MODELS_DIR`) 아래 `adtof_ft/tom_6cls_real_full/best.pth`, `adtof_ft/tom_7cls_real_full/best.pth`
