# 탐 구분: 새 킷 규칙 검증·채보 모델 파인튜닝 결과 (S15P31A307-164)

측정일 2026-10-29~31 · 모델 ADTOF + 드럼 킷 분리(`adtof_drumsep`) · 입력 정답 드럼 트랙 · GPU 서버(학습·특징 저장)와 저장 특징 규칙 채점(`rule-eval`, CPU) · 탐 3종 F1은 50ms, 탐 둘인 곡의 위쪽 탐은 미드로 채점(`--two-tom-upper MID_TOM`)

## 결론

- 실제 녹음 탐 3종 F1 0.6 이상이라는 목표는 MDB에서만 이룸. 규칙 pk_gap30으로 MDB 0.213 → 0.671. 학습·튜닝에 안 쓴 실제 녹음 ENST는 0.236 → 0.297로 목표에 못 미침. 처음 보는 실제 킷에서 탐 세 종류를 가르는 문제는 풀지 못함
- 기본값을 pk_gap30 + 크래시 가중치 0.7(cx07)로 바꿈. 고정 경계 대비 탐 3종 F1이 다섯 평가 데이터 모두에서 오름(아래 1절). `configs/bench/transcribers/adtof_drumsep/adtof_drumsep.yaml`
- ADTOF 파인튜닝 3종(`tom_5cls`·`tom_6cls`·`tom_7cls`)은 채택하지 않음. MDB 탐은 0.671 → 0.744로 오르고 다른 패드도 크게 오르지만 ENST 탐이 0.297 → 0.11~0.12로 떨어짐. 떨어진 몫은 거의 전부 ENST 드러머 1의 실제 킥을 플로어탐으로도 내는 것(4절). 킥과 겹친 탐 지우기 규칙으로도 0.20까지만 돌아옴(5절)
- 하이햇 페달은 채택 기준(MDB·GMD 페달 F1 0.5 이상, 정밀도 0.6 이상)을 못 넘어 운영 출력에서 계속 `HIHAT`에 합침(6절)
- 크래시·라이드는 규칙 cx07만 채택. 크래시·라이드를 직접 내는 `tom_7cls`는 E-GMD 크래시·라이드 합산 F1을 0.643 → 0.903으로 올리지만 같은 모델의 탐 하락 때문에 기각(7절)

## 2. 파인튜닝 설정

- 시작 가중치는 ADTOF 기본 가중치(Frame_RNN, 파라미터 45만 개). 입력은 정답 드럼 트랙
- 학습 데이터: E-GMD train 어쿠스틱 26킷 21,294개(비율 0.5), STAR training ISMIR04(0.2)·MTG-Jamendo(0.2). 검증은 E-GMD validation 20곡 + STAR validation 20곡. 평가 데이터(MDB·ENST·GMD test·E-GMD test·STAR test)와 겹치지 않음
- 윈도의 절반을 정답 탐 타격 중심으로 자름, 탐 클래스 가중치 ×2, 학습률 0.0001, 에폭당 2,000스텝, 최대 20에폭, 조기 종료 4에폭, 학습 끝에 검증 곡으로 클래스별 문턱값 맞춤
- `tom_5cls`: 5클래스 그대로. `tom_6cls`: + 페달 하이햇 출력. `tom_7cls`: + 페달, 심벌을 크래시·라이드로 나눔. 설정 `configs/train/adtof_tom_{5,6,7}cls.yaml`
- 검증 탐 F1(기본 가중치 0.407) → 5cls 0.748, 6cls 0.744, 7cls 0.757

## 4. ENST에서 탐이 떨어진 이유

- 정답 탐과 짝이 안 된 탐 예측이 기본 462개 → 6cls 3,347개. 그중 3,268개가 드러머 1(21곡), 거의 전부 FLOOR_TOM
- 드러머별 탐 3종 F1 기본 → 6cls: 드러머 1 0.073 → 0.031, 드러머 2 0.540 → 0.659, 드러머 3 0.519 → 0.510. 드러머 2·3만 보면 0.525 → 0.542로 떨어지지 않음
- 드러머 1의 정답 없는 탐 자리 ±50ms의 ENST 원래 주석(`false-toms-enst-drummer_1.md`, `scripts/check_false_toms.py`), 기본 → 6cls:
  - 킥만 있고 스네어 없음 4% → 39%, 킥이 있는 자리 전체 51% → 64%
  - 같은 자리 ±30ms에 ADTOF 킥 타격도 있음 14% → 42%. 학습 모델이 같은 킥을 킥과 플로어탐으로 함께 냄
  - 정답 없는 탐의 탐 확신 점수 중앙값 0.87, 맞은 탐 0.97. 점수 기준값으로는 못 가름
- 학습 데이터가 전자 드럼 녹음(E-GMD)과 샘플 합성(STAR)뿐이라 드러머 1 킷 같은 실제 킥 소리를 학습하지 못한 것으로 추정함. 확인한 것은 자리가 킥이라는 데까지임. ENST는 이용 조건이 평가 전용이라 학습에 넣을 수 없음

## 8. 남은 원인과 후속 작업

- 처음 보는 실제 킷의 킥을 탐으로 냄: 학습 데이터에 실제 녹음 킷이 없음. 후속 작업 후보 "[CHART-003 | AI] 실제 녹음 드럼 학습 데이터 확보와 탐 파인튜닝 재시도"
- 같은 음높이 두 드럼: 실제 킷은 플로어탐과 미드탐 음높이가 겹치기도 해서(MDB FreeJazz 163·164Hz, Punk 91·94Hz) 음높이만으로 못 가름
- 분리 모델의 낮은 탐: 드럼 킷 분리 모델이 80Hz 안팎 플로어탐을 kick 트랙에 넣어 거르기에서 빠짐(MDB Grunge 12개)
- 정답 정의: 전자 드럼 데이터는 탐 둘 연주의 위쪽 탐을 스몰, 실제 킷 데이터는 미드로 적음. 채점은 미드로 맞춤
- 서비스 영향: 처음 보는 실제 킷에서는 탐 이름이 틀릴 수 있음. FE·BE에 알려진 한계로 전달
