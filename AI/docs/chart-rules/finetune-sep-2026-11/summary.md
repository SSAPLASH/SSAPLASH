# 파인튜닝 가설 1~5 결과

측정일 2026-11-07 · `ai_2_to_4.md` 8.11 파인튜닝 가설 · 로컬 RTX 4070 Laptop · 모델 ADTOF Frame_RNN + 드럼 킷 분리 + 서비스 규칙(탐 그룹·심벌 에너지) · F1 ±50ms · ENST `c1`·`c4`는 RIDE로 채점 · 탐 둘만 쓴 곡의 위쪽 탐은 미드로 채점

## 결론

- 채택하는 것 없음. 학습한 가중치 6종 모두 평가 전용 ENST에서 탐 3종 F1이 0.298에서 0.10~0.16으로 떨어졌다. 무너지는 자리는 예전(-164)과 같다: 드러머 1에서 정답에 없는 탐이 385개에서 1,500~4,300개로 늘어난다
- 실제 어쿠스틱 키트 10종 렌더링(가설 1·2)은 드럼 단독 입력의 드러머 2·3 탐 3종을 0.526 → 0.587·0.577로 올리고 정답에 없는 탐을 77 → 48·58로 줄였다. 학습으로 처음 나온 개선이지만, 드러머 1에서 무너지고 반주를 분리한 입력에서는 드러머 2·3도 0.327 → 0.29로 떨어진다
- 기본 가중치에 E-GMD 검증 40곡으로 클래스별 문턱값만 다시 맞춘 것은 ENST 8패드를 올렸지만(드럼 단독 +0.010, 분리 입력 +0.021), MDB에서는 오르지 않고 심벌이 떨어졌다(−0.017). 채택하지 않는다
- E-GMD 점수로 패드 묶음마다 가장 좋은 가중치를 골라 합친 조합은 ENST 8패드를 −0.055·−0.039 떨어뜨렸다
- 이번 실험 전부에서 E-GMD(전자 드럼 음색)로 오른 것이 실제 녹음으로 옮겨 가지 않았다. 서비스 설정은 그대로다

## 1. 학습 설정

- 학습 데이터: E-GMD train 어쿠스틱 26킷에서 키트마다 30개(780곡, 4.6시간). 배포 zip에서 이 곡만 HTTP 구간 요청으로 받음(zip 안 CRC 확인)
- 공통: `configs/train/adtof_tom_5cls.yaml`과 같고 학습·검증 데이터, 에폭 5, 데이터 읽기 작업 4만 바꿈. 검증은 E-GMD test 어쿠스틱 40곡. 설정 파일은 이 폴더 `train_*.yaml`, 데이터셋 `egmd_train30_*.yaml`
- 학습 코드는 5종 가운데 하나라도 검증 F1이 기본 가중치보다 0.02 넘게 떨어진 에폭을 `best.pth`로 고르지 않는다. 그래서 분리 드럼·가설 1·가설 2는 `best.pth`가 기본 가중치에 문턱값만 맞춘 파일이 됐다(모든 에폭에서 심벌이 기준보다 떨어짐). 학습 효과는 `last.pth`(마지막 에폭)로 본다

| 이름 | 학습 입력 | 만든 방법 (스크립트) |
| --- | --- | --- |
| h_clean | 원래 E-GMD 드럼 (비교 기준) | — |
| h_sep (가설 3) | MUSDB18-HQ train 반주를 드럼 RMS 0.5~2배로 섞고 BS Roformer SW로 다시 뽑은 드럼 | `scripts/make_egmd_separated.py` |
| h1 (가설 1) | 원래 + 같은 MIDI를 StemGMD 단타 샘플(실제 어쿠스틱 키트 10종)로 렌더링, 반반 | `scripts/render_stemgmd_kits.py` |
| h2 (가설 2) | 원래 + 렌더링에서 곡마다 킥 0~+12반음, 탐 −5~+2반음 옮김, 반반 | 같은 스크립트 `--pitch-shift` |
| h4 (가설 4) | 같은 키트 다른 곡을 0.5~1배로 겹침. 30ms 안 이웃 타격 비율 0.271 → 0.312 | `scripts/make_egmd_overlay.py` |
| h5 (가설 5) | 원래 드럼, 탐 3종을 모델이 직접 내는 9패드 출력(`classes: pads`) | — |

- 렌더링 킥 음높이 중앙값: 그대로 41.7Hz, 옮긴 것 54.2Hz. ENST 드러머 1 킥(100Hz)에는 못 미친다
- 학습한 에폭 수: h_clean·h4는 5에폭, h_sep·h1·h2·h5는 4에폭에서 끝났다. 일찍 끝난 이유는 로그로 확인하지 않았다
- h4는 3에폭이 0.02 기준을 넘어 `best.pth`로 골라졌고, h1·h2·h_sep은 모든 에폭에서 심벌 검증 F1(0.776~0.825, 0.547~0.731)이 기준 0.857보다 0.02 넘게 낮았다
- 학습 시간: 에폭 하나 8~9분. 노트북이 덮인 동안 멈춘 시간이 기록에 섞인 에폭이 있다

## 4. 기본 가중치 + 문턱값만 다시 맞춤

- h_sep 학습이 마지막에 E-GMD 검증 40곡으로 기본 가중치의 문턱값을 맞춘 결과다. 킥 0.22 → 0.14, 스네어 0.24 → 0.10, 하이햇 0.22 → 0.16, 심벌 0.30 → 0.22. 탐은 서비스 규칙이 문턱값 0.32로 따로 다시 골라서 영향이 없다
- ENST: 8패드 드럼 단독 +0.010(+0.000 ~ +0.023), 분리 입력 +0.021(+0.011 ~ +0.034). 드러머 1 킥 +0.069·+0.091, 스네어 +0.026·+0.060, 하이햇·라이드는 일부 그룹에서 −0.01 안팎
- MDB(`data/rule_features/mdb_drums`, 드럼 단독): 23곡 8패드 0.854 → 0.853(−0.002, −0.016 ~ +0.014), MIREX test 11곡 0.852 → 0.842(−0.010, −0.025 ~ +0.007), 심벌 23곡 −0.017(−0.026 ~ −0.011). 결과 `data/results/finetune/mdb_thr.csv`
- 판단: 데이터에 따라 갈려 채택하지 않는다. ENST 이득은 드러머 1의 높게 조율한 킥에 몰려 있다

## 5. 패드 묶음별 조합

- E-GMD test 1,170곡에서 묶음마다 F1이 가장 높은 가중치를 골랐다(`data/results/finetune/egmd_ckpts.csv`): 킥·스네어 h_clean last, 탐 h1 last, 하이햇·심벌 h2 last. 학습 가중치가 E-GMD 8패드를 0.657(기본)에서 0.79~0.80으로 올려 모든 묶음에서 앞섰다
- ENST 8패드: 드럼 단독 0.828 → 0.773(−0.055, −0.075 ~ −0.033), 분리 입력 0.785 → 0.746(−0.039, −0.059 ~ −0.017). 킥만 오르고(0.882 → 0.915) 탐·하이햇·심벌이 떨어진다
- ENST 패드별 결과를 이미 본 뒤라 ENST를 보고 조합을 다시 고르지 않았다

## 6. 기록

- MLflow 로컬 `mlruns/`: 실험 `ai2to4-finetune`(학습마다 에폭별 검증 지표, best·last의 ENST·E-GMD·MDB 지표), `ai2to4-pad-combo`. 기록 스크립트 `scripts/log_ai2to4_mlflow.py`
- 가중치 `data/models/adtof_ft/h_*`(git 미추적), 학습 로그 `data/models/adtof_ft/h_*.log`
- 채점 스크립트가 ADTOF를 다시 돌려 낸 기본 가중치 결과는 저장 특징 결과와 1,664칸 중 6칸 달랐다(CPU 실행, 탐 3종 0.298 대 0.297). 모든 가중치를 같은 스크립트로 채점해 비교에는 영향이 없다
